# LiveLyricOverlay 🎵

LiveLyricOverlay 是一款专为 foobar2000 (FB2K) 打造的高级、美观、且高度可定制的桌面悬浮歌词渲染引擎。基于强大的 SkiaSharp 图形库构建，拥有丝滑的渲染性能与极致的视觉体验。

## ✨ 核心特性

- **硬件级图形渲染**: 采用 SkiaSharp 引擎，提供极致平滑的文本抗锯齿与像素级渲染质量。
- **智能卡拉OK动效**: 完美支持卡拉OK模式（逐字变色高亮），提供丝滑跟手的逐字高亮动画。
- **双语歌词自适应**: 自动检测并优雅排版中外双语歌词（主/副双行显示）。
- **超长歌词平滑滚动**: 当单句歌词过长超出窗口宽度时，歌词会根据当前歌曲演唱进度，非常平滑地自动向左滚动。
- **智能多语言回退 (Font Fallback)**: 当歌词中出现韩文、日文等当前字体不支持的字符时，引擎会自动回退到系统字体，彻底告别“方块字”。
- **全配置热重载 (Hot-Reload)**: 支持配置文件的极速热重载，无需重启程序即可实时呈现修改效果。
- **专属可视化配置工具**: 附带独立的 WPF `LiveLyricOverlayConfig` 图形配置器，支持所见即所得的像素级预览和拾色器功能。

## 🛠️ 配置项说明

使用 `LiveLyricOverlayConfig` 工具可以轻松配置以下选项，或者你也可以手动编辑 `config.json`：

- **字体与排版**：支持自定义主/副歌词字号，自定义系统字体。
- **色彩与渐变**：支持配置未播放/已播放字体的独立颜色，并且支持**上下双色渐变渲染**。
- **高级特效**：
  - 描边效果：可自定义描边宽度与颜色。
  - 阴影效果：支持定义阴影半径（模糊度）、颜色以及 X/Y 轴独立偏移量。
- **卡拉OK模式**：支持一键开关卡拉OK逐字变色特性。

## 🚀 快速启动

1. **配置 foobar2000 端**
   请确保你已经在 fb2k 端正确配置了配套的 `foo_run` 或 IPC 通信插件，将播放和歌词事件发送至命名管道 `LiveLyricOverlayPipe`。

2. **启动主渲染程序**
   进入 `LiveLyricOverlayApp` 目录并运行生成的 `.exe`。
   程序启动后将自动隐去控制台窗口，在桌面浮现歌词，并等待 fb2k 客户端的接入。

3. **打开可视化配置**
   运行 `LiveLyricOverlayConfig` 对悬浮歌词的字号、阴影、渐变色进行“所见即所得”的调整。点击“应用”即可在桌面直接看到效果！
